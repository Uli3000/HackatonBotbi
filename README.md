Aqui esta mi propuesta del hackaton con las tareas indicadas hecho con React y typescript por la parte de frontend y con node exxpress por la parte del backend, cuenta con uso de varias librerias como:
-React Router Dom
-Axios
-Zod
-React Hook Forms
-Sonner
Pasos para instalacion:
Requisito previo contar con node y git instalados
1- git clone https://github.com/Uli3000/HackatonBotbi en la terminal
2- Abrir el codigo en tu editor
3- Copiar el contenido del archivo BotbiHackatonDb y crear la base de datos
4- Actualizar los datos de la db en el archivo .\HackatonBotbi\Back\src\config/db.js
5- Abrir una terminal parra el front y hacer: cd .\Front\ luego cd .\Pagina-Botbi\ luego npm install y finalmente npm run dev
6- Abrir en otra terminal el back con desde fuera de las carpetas: cd .\Back\ y node .\src\server.js
7- Abrir la direccion que te dio la terminal del front y probar, normalmente es algo como esta http://localhost:5173/
